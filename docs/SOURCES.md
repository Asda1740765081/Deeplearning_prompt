## 本地内容变化

- 增加检索与筛选策略、证据摘录卡、论点证据审计、研究问题与假设、统计分析计划、复现就绪检查、结果讨论、学术翻译。
- 增加论文故事线与大纲、引言、方法、结果、基于证据的完整论文初稿。
- 速读改为证据与信息缺口判断，取消未经校准的可靠性分数；精读限定材料范围；文献矩阵区分本批材料缺口与领域空白；润色保留不确定性和因果边界。
- 这些模板在编辑器展示交付物、人工核验清单与来源链接。

## 验证与边界

检查占位符与填写字段匹配、示例输出、分类浏览、草稿恢复和新模板入口。音效默认静音，只有用户开启并点击才使用本地 Web Audio 合成；不下载音频。支持减少动态效果。

这不是模型效果评测。统计模板准备分析计划，不代替统计检验；完整初稿依赖作者已有材料，不生成虚构研究，引用、数字、伦理声明和论证均需作者核验。本轮内容随 v0.3.0 发布，v0.2.0 的历史版本说明保留不变。
