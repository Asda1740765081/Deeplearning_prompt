# 隐私与能力边界

## 浏览器数据

应用使用 `localStorage` 保存 `dp-custom`（个人模板）、`dp-favs`（收藏）、`dp-recent`（最近使用）、`dp-ratings`（个人评分）、`dp-drafts`（草稿）、`dp-theme`（主题）、`dp-sound`（音效开关），不会由应用代码上传。

存储按地址区分。本地文件、localhost 与 GitHub Pages 的数据不自动共享。清理浏览器、隐私模式、配额限制或更换设备可能导致丢失；JSON 可迁移，但不是加密备份。

## 分享和导入导出

论文写作流程的阶段选择和人工核验清单单独保存在 `dp-writing-flow`，只维护当前浏览器的一份流程状态，暂未纳入 JSON 备份。网站不据此判断实际研究或写作任务已经完成。

- 新分享链接包含模板 ID；个人模板还包含标题、正文和标签等，不包含填写字段的值。
- Base64 不是加密，获得链接的人可以读取模板正文。
- 分享给其他设备时请使用在线演示地址；本地文件和 localhost 链接通常只在当前电脑可访问。
- 兼容旧版 `#share=` 链接；旧链接可能包含填写值，读取时不会覆盖已有草稿。
- JSON 备份包含草稿、收藏与评分，可能包含你的研究材料，不要随意公开。
- 导入在本地校验和合并，相同标题与正文的个人模板不重复添加，现有草稿优先保留。

## 网络和外部工具

`index.html` 内嵌样式、模板和脚本，无统计 SDK、字体 CDN、模型 API 或外部脚本依赖。GitHub Pages 可能按其政策记录访问请求；README 的徽章向 GitHub 或 shields.io 加载图片。

点击外部链接或将材料复制到 AI 工具后，由相应服务处理。本站无法替你控制外部工具的数据政策或输出。

## 能力边界

本项目整理指令，不执行文献检索、数据分析、训练、修复、文件生成或自动 Agent 协作。角色与双模型工作流需要人工复制、执行和审核。

请核验引用是否存在、数字是否来自材料、代码是否实际运行、结论是否得到证据支持。个人星级是自己的使用记录，不是公共质量排名。

数据泄露相关问题请参考 [SECURITY.md](../SECURITY.md)。

点击音效默认关闭，开启后由浏览器 Web Audio 本地合成，不请求音频资源。减少动态效果设置会关闭界面动画。
