# 论文写作流程

点击左侧“论文写作”，默认进入流程视图。首页“开始论文写作流程”也会打开同一入口。“浏览全部写作模板”可切换到原来的搜索与模板库。

## 从哪里开始

- 只有选题或零散笔记：先“整理研究材料”。
- 已有方法和实验：从“确定故事线与大纲”开始。
- 已有完整草稿：从“语言与证据核验”开始。

## 建议顺序

1. 整理研究材料：明确问题、证据与缺失项。
2. 确定故事线与大纲：将贡献与证据对应。
3. 先写方法与结果：准确记录做了什么、得到了什么。
4. 写引言与相关工作：根据实际结果校准研究定位。
5. 讨论解释与局限：区分观察、解释与未来工作。
6. 整合全文与摘要：统一术语、摘要与结论，保留待补项。
7. 语言与证据核验：逐项核对数字、引用、论证和表达。
8. 投稿前预审：对照目标要求、检查稿件，实际提交由作者操作。
9. 修回与逐点回复：收到意见后补证、修稿、回复，再回到核验阶段。

这是建议顺序，可以按稿件状态跳转。没有完成实验不应通过模板补造结果；没有收到审稿意见时，不必进入修回。

每个阶段列出“什么时候用”“准备什么”“做到什么再往下走”，并区分按顺序使用的主模板与按需展开的辅助工具。模板编辑器末尾可返回当前流程，查看交付与下一阶段。

## 进度与材料

“标记本阶段已核验”是人工确认，可以撤销。打开、填写或复制模板不会自动标记完成。阶段选择和完成清单保存在 `dp-writing-flow`；当前只维护一份浏览器内的清单，不区分多篇稿件。

网站不运行外部 AI，不自动传递模型输出。需要将核验过的上一阶段产物自行带入下一阶段。现有 JSON 备份包含模板、草稿、收藏与评分；流程清单目前不包含在备份中，清除网站数据会清除它。
