# DeepPrompt Lab v0.3.0

本次更新把论文写作从模板列表整理为有起点、顺序和交付标准的流程，并补全科研任务模板。

- 46 个模板：新增13个科研与论文写作模板，升级4个原模板的证据约束。
- 九阶段论文写作：材料准备 → 故事线与大纲 → 方法与结果 → 引言与相关工作 → 讨论 → 全文与摘要 → 语言与证据核验 → 投稿预审 → 修回。
- 支持按准备程度选择起点；阶段包含输入、交付、主模板顺序和可选工具；可切换到完整模板库。
- 人工标记阶段完成并在本地保存，模板末尾可返回流程查看下一步。
- 改善卡片与编辑器层次；新增默认静音、可开关的点击音效；动画尊重减少动态效果设置。
- 增加参考来源与许可核对记录，科研模板展示预期交付和核验清单。

验证：8组核心测试、17项浏览器验收，涵盖模板生成、备份恢复、分享、流程导航、进度持久化、音效控制、手机布局和本地文件打开。云端执行结果以 [Actions](https://github.com/Asda1740765081/Deeplearning_prompt/actions/workflows/ci.yml) 为准。

已知边界：网站整理指令，不调用模型或自动完成研究；各阶段产物需要人工核验并自行带入下一步。当前浏览器只有一份流程清单，不区分多篇稿件；清单暂未纳入JSON备份。不同访问地址的浏览器数据需手动迁移。引用、数字、论文结论和投稿声明均需作者核验。
