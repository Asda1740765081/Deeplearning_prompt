# 验证范围

v0.2.0 的检查围绕网站行为，使用公开演示数据，不访问模型 API。

## 确定性检查

`npm run check` 执行构建一致性、7 组核心测试和三份案例输出一致性检查：

| 对象       | 检查内容                                                     |
| ---------- | ------------------------------------------------------------ |
| 模板和角色 | 33 个唯一 ID、有效分类、字段和占位符匹配；7 个角色有有效入口 |
| 变量替换   | 中文、重复变量、缺失项、特殊字符；输入不被再次解析为模板     |
| 输出语言   | 英文要求保留原材料、公式与代码                               |
| 分享       | Unicode 往返，拒绝无效、超大、不完整载荷                     |
| 导入       | 去重、ID 冲突重映射、无效条目与版本拒绝；失败不改原集合      |
| 案例       | 三组固定输入的实际指令与提交文件一致                         |

## 浏览器验收

`npm run test:e2e` 启动本地服务和隔离浏览器，包含 13 项检查：

1. 模板与场景数量。
2. 关键词和难度筛选。
3. 三个案例的实际预览。
4. 草稿和语言刷新恢复。
5. 收藏持久化和筛选。
6. 中文变量、编辑与 HTML 转义。
7. JSON 导出、恢复收藏/评分/草稿、去重与非法 JSON。
8. 分享不含填写数据、保留草稿、重新打开自定义模板。
9. 七个角色入口。
10. 390 × 844 手机导航、编辑器宽度和横向溢出。
11. 存储失败提示。
12. 直接打开本地文件。
13. 桌面验收流程无未捕获页面异常。

2026-10-21 本地验收使用 Windows、Playwright 1.62.1 和已安装的 Edge。CI 使用 Ubuntu、Node.js 22 和 Chromium；以 [Actions 的运行记录](https://github.com/Asda1740765081/Deeplearning_prompt/actions/workflows/ci.yml)为准。截图由同一脚本、固定演示输入生成。

## 未覆盖与限制

- 尚未全面验证 Safari、Firefox、所有手机与屏幕阅读器。
- 本地文件的剪贴板和存储由浏览器决定，复制失败时提示手动复制。
- 多标签编辑没有冲突解决；清理浏览器或超出配额可能丢失数据。
- JSON 和分享未加密，旧分享可能包含填写材料。
- 测试不评估模型回答、推导正确性、论文质量、实验有效性或用户效率。
